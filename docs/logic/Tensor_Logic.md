# GPU Tensor Core Load Logic (텐서 코어 부하 모듈 로직 설명)

이 문서는 `gpu_tensor.cu` 모듈이 어떻게 최신 AI 워크로드(LLM 추론, 딥러닝 등)의 핵심인 **텐서 코어(Tensor Core)** 만을 집중적으로 혹사시키고, 그로 인한 극한의 발열과 전력 스파이크를 안전하게 제어하는지 친절하게 설명합니다.

---

## 1. 하드웨어적 부하 원리 (Why Tensor Cores?)

기존의 범용 CUDA 코어는 1차원적인 스칼라 부동소수점 연산(FMA)을 수행합니다. 반면 텐서 코어는 딥러닝 행렬 곱셈을 위해 탄생한 전용 하드웨어 유닛으로, 단 1클럭 사이클(Tick)만에 거대한 4x4 혹은 16x16 배열 데이터 전체를 곱하고 더하는 **MMA(Matrix Multiply-Accumulate)** 연산을 수행합니다.

이러한 막대한 연산 집적도 때문에 텐서 코어가 가동되는 순간, 아주 좁은 다이(Die) 영역에 **폭발적인 전류가 몰리며 극심한 국소 발열(Hot-spot)과 전력 스파이크**가 발생합니다. 본 모듈은 이 특성을 활용하여 실제 AI 데이터센터에서 발생하는 가장 파괴적인 전력/발열 패턴을 모사합니다.

---

## 2. 코드 제어 로직 (MMA Isolation & Micro-Duty Cycle)

### ① VRAM 통신 차단 (순수 연산 고립)
메모리 대역폭 부하와 코어 부하가 섞이면 열 발생 원인이 분산되어 정교한 측정이 어렵습니다. 따라서 `nvcuda::wmma` (Warp-Level Matrix Operations) API를 사용할 때 데이터 조각(Fragment)을 외부 메모리(VRAM)에서 불러오지 않습니다. 대신 **레지스터(Register)와 L1 캐시(Shared Memory) 내부에만 FP16 더미 데이터를 고정**해두고 무한 곱셈 연산을 반복하여, 오직 텐서 코어 회로만 달굽니다.

### ② 마이크로초(µs) 단위 타임 슬라이싱
일반적인 OS의 `Sleep` 타이머는 10~15ms의 오차가 발생합니다. 텐서 코어의 경우 10ms만 방치되어도 파워서플라이 차단기가 내려갈 수 있습니다. 이를 막기 위해 **CUDA 스트림 동기화(cudaStreamSynchronize)**와 CPU Spin-wait(Busy Loop) 기법을 결합하여, 마이크로초 단위로 아주 짧게 연산을 치고 빠지는 초정밀 Duty Cycle 제어를 수행합니다.

## 3. 엣지 케이스 및 안전 장치 (Safety Mechanism)

텐서 코어의 파괴력으로부터 하드웨어를 보호하기 위해 삼중 안전망이 적용되어 있습니다.

- **점진적 부하 증가 (Graceful Ramp-up)**: 가동 즉시 목표 부하율을 쏟아내지 않고, 첫 5초간 1%에서 목표치까지 선형적으로 서서히 부하를 올립니다. (전원부 충격 완화)
- **하드웨어 전력 락 (Hardware Power Limit)**: OS 스케줄러가 멈추거나 꼬이는 최악의 상황(Software Hang)에 대비해, 모듈 가동 직전 NVML API를 호출하여 GPU 펌웨어 단에 절대 전력 상한선(예: TDP 60~70%)을 물리적으로 걸어 잠급니다. (프로그램 종료 시 원상 복구)
- **펌웨어 스로틀링(Throttling) 감지**: 온도가 높아져 GPU가 스스로 클럭 스피드(Clock)를 낮출 경우, 제어 루프가 이를 실시간으로 눈치채고 부하량을 강제로 밀어넣지 않고 상황에 맞춰 유연하게 동기화합니다.

---

## 4. 사용 가이드 (Usage Guide)

텐서 코어 모듈을 단일 실행하기 위해서는 터미널에 아래와 같이 입력합니다. (Hardware Power Limit 제어를 위해 `sudo` 권한을 적극 권장합니다.)

```bash
# 텐서 코어를 활용해 부하를 25% 수준으로 맞추고 60초간 유지
sudo ./build/gpu-stressor --type tensor --percent 25 --duration 60
```

> **주의:** 텐서 코어 모듈의 `--percent`는 CUDA 코어(Util)보다 훨씬 더 치명적인 발열을 유발하므로, 절대 30%를 넘지 않도록 코드 내부에 안전 상한선이 걸려있습니다.
